## 📖 ABOUT
 
This repository is an **archive of README write-ups** for publicly disclosed Microsoft zero-day proof-of-concepts (PoCs).
 
Original repositories can be deleted, taken down, or renamed at any time. If the original content goes extinct, this repository acts as a **reference and archive** so the research is not lost.
 
> Every entry links back to its original source and credits its author. Nothing here is claimed as my own work.
